## Run locally

Open `index.html` in any browser.

## Deploy on GitHub Pages

1. Push these files to a public repo named `laiba-aftab-portfolio`.
2. Go to **Settings**, then **Pages**.
3. Set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.

## Contact form

The form works out of the box by opening the visitor's email app. To receive messages directly in your inbox:

1. Create a free form at [formspree.io](https://formspree.io).
2. In `index.html`, replace `YOUR_FORM_ID` in the form's `action` with your form ID.
